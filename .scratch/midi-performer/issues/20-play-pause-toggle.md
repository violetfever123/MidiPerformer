# 20: 播放 / 暂停合并成一个键与一个按钮

**What to build:** `Space` 一次开始、再按一次**暂停**（播放头停在原地）、再按从那里继续；
走带条上播放和暂停合成一个切换按钮。

**几处要说清楚的决定：**

- **现在没有「暂停」这个概念。** 只有 `▶ 从当前位置播放` 和 `■ 停止` 两个按钮、两个状态。
  这条工单要**新增暂停状态**。
- **暂停 = 播放头原地不动**，再按从那里接着放。不是回到起点，也不是 `■ 停止`。
- **走带条**：`▶ 播放` / `⏸ 暂停` **一个切换按钮**；`■ 停止` **保留为独立按钮**。
  理由：暂停和停止是两件事 —— 「我就停在这，等下接着听」和「这段我听完了」。
- 暂停时按钮变 `▶ 继续`；`■ 停止` **始终可用**。
- `■ 停止` 的现有行为**不改**（包括那一下把视图 snap 回小节）。
- **这是一条被推翻的旧决定。** 现在 `Space` 只**开始**播放，播放中按没反应（因为按钮被禁用），
  而且代码里有一句当初特意写的注释反对一个键管两头，原型文档里也明确写着
  「空格 = 播放的快捷键；播放中按空格没反应（和按钮一致）」。**推翻它的理由**：
  那条决定缺的正是暂停 —— 当时没有暂停可切，所以「一个键管两头」确实会让人迷失；
  现在两头是「放」和「停在这」，不会迷失。文档照实改在 27 号工单。
- `Space` **无条件抢占**，但**焦点在输入框里时让开**（现有守卫保留）。
- `F6` 急停不动。
- 播放按钮的 ToolTip 现在写着「（空格键同效）」，改它属于 26 号工单，**这条不改**。
- 播完自动停止后，状态要回到「能按 `Space` 重新开始」，不能卡在「暂停中」。

**Blocked by:** 无（可以立刻开工）

**Status:** ready-for-agent

- [ ] `Space` 开始播放；再按暂停（播放头停住不动）；再按从暂停处继续
- [ ] 暂停期间 `■ 停止` 可用，按了走现在的停止行为
- [ ] 走带条上播放/暂停是**一个**按钮，标签在 `▶ 播放` / `⏸ 暂停` / `▶ 继续` 之间正确切换
- [ ] 暂停之后接着放，是从暂停那一刻的时间点接下去，不是从头、也不是从播放起点
- [ ] 焦点在任一输入框里时，`Space` 输入空格，不触发播放
