# 31: 界面删掉按值认音的选中镜像

**What to build:** 界面不再需要「拿音符内容去重新认音」，那套约 100 行的按值镜像整个删掉。

**几处要说清楚的决定：**

- `MainWindow` 现在有一套**按值**的选中集镜像：记录选中音是什么样（轨 + 音高 + 起点 + 时值 +
  力度），命令跑完之后，拿这份内容去新的 `Track.Notes` 里**重新找**它在哪，再把下标装回选中集。
  配套六七个方法（捕获、捕获值、算挪完之后的选中、算改完时值之后的选中、恢复、按内容查音）。
- 它们存在的**唯一原因**是 `NoteRef` 是下标寻址（30 号工单）。
- 30 号工单之后，选中集**直接用身份表示**，命令跑完身份照样有效，
  **改完不需要重新认音** —— 于是这一整套东西连同它的方法全部删掉。
- 删掉之后，`ApplySong` 里那两处「改完把选中集恢复回去」的调用**也跟着消失**。
  这是这套镜像的入口，入口没了说明删干净了。
- **依赖 19**：19 号工单**在同一个位置加过代码**（删完音符后选中回落到时间上最近的邻居），
  而那个回落**也要靠这套镜像重新认音**。如果 31 先做，19 就得重写一遍。
- **删的时候注意**：`MoveNotes` / `SetNoteSpan` 仍然会**重排** `Track.Notes`
  —— 那是 29 号工单在 `Track` 里收口的不变量，**跟认音无关**。
  只是界面**不再需要为此做任何事**了。这个区别要分清楚，否则会误以为「不重排了、镜像也不用删」。

## 哪些是测出来的、哪些只是写出来了

**改了什么**（17 个文件；这里只说界面那一侧，寻址那一侧在 30 号工单的收尾里）。

- **整套按值镜像删掉了**：`SelectedNote` 记录、`CaptureSelection`、`SelectionAfterMove`、
  `SelectionAfterResize`、`RestoreSelection`、以及按内容查音那一支，一个不留。
- **`ApplySong` 的第二张嘴换了意思**。从前是 `IReadOnlyList<SelectedNote>? selectionAfter`：
  收的是「编辑之后该选中哪几个音」的**值**，由上面那几个方法算出来，再拿值去新曲子里**重新找下标**。
  现在是 `IReadOnlyList<NoteRef>? selectionAfter`，而且**绝大多数命令根本不传** ——
  坐标按身份寻址，命令换的是内容不是身份，原样留着就是对的。
  传的只剩三种：删音符（落点换成邻居）、删整条轨、抽掉一段（坐标的轨那一半当场作废）。
- **`RestoreSelection(selection)` 换成 `_controller?.SetSelection(selection)`** ——
  「重新认一遍」这件事整个没有了，只剩「把同一串坐标交给新控制器」。认不出的由 `SetSelection` 丢掉。
- **`NoteAt` 留着没删**，这是个要说得清的区别：删掉的是「**拿内容去重新认音**」，
  「**按一个坐标去取那个音**」还得留着（删音符要拿被删那组里最靠右那个的起点当落点基准）。
  而且它现在**精确**了 —— 内容一模一样的两个音也分得开。
- **行数**：`MainWindow.axaml.cs` +105 −155（净 −50）、`PianoRollLane.cs` +51 −31、
  `TrackLaneView.axaml.cs` +10 −7，`MidiPerformer.App` 整层**净 −27**。
  没到「界面大幅缩水」那么好看，因为悬停那条事件从 `int?`（下标）换成了 `NoteId`（结构体），
  `PianoRollLane` 反而长了一点。**这张单要的是删掉认音的逻辑，不是删行数。**

**一处必须显式处理的残留**：轨那一半**还是下标**（·删掉一条轨，后面的整体前移）。
坏在它**不会**认不出来 —— 身份号是从 1 开始按轨连号发的，换一条轨照样能撞上一个号，
于是 `SetSelection` 那道「认不出就丢掉」根本拦不住，用户会看到选中莫名其妙落在**别条轨**的音上。
所以 `OnTrackDeleteRequested` 必须**显式交一份空表**。这是身份寻址剩下的唯一一处位置语义，
注释写在 `NoteRef` 和 `OnTrackDeleteRequested` 上，**这一条在真界面上量过**（见下第 7 节）。

**机器测过的**：`dotnet build` → 0 警告 0 错误；`dotnet test` → **1601 通过 / 0 失败**。

**跑起来量过的**（`.scratch/verify-31.ps1`，7 节 **43 条断言，全过**；app 真跑，
曲子是 `Carulli_Duetto_No2_Op4`，脚本自己截图扫出音符位置，不写死坐标）：

量具是 **21 号刚合并出来的读数条** —— 它显示的正是「此刻算在选中头上的那个音」的
轨/音高/小节/拍位/时值。判据统一是：**改完位置动了、别的字段一个不动；再改回去五格逐字回到原样。**
逐字回到原样 = 身份没丢；镜像要认错音，回来的是别人。跑了**两遍**，两遍扫到的是不同的音
（一遍 E4 第 2 小节第 1 拍、一遍第 2 拍），不是撞运气。

- **挪时间 →×8 再 ←×8**：`2 / 2.00 拍 → 3 / 1.00 拍`，音高/时值/轨一个字节没动；
  回来五格逐字等于出发前。**这条是真重排** —— 见下面那条更正。
- **挪音高 ↑×5 再 ↓×5**：`E4（3）→ A4（6）`，小节/拍位/时值一个不动；回来逐字等于出发前。
- **改时值 Shift+→ 再 Shift+←**：`1.00 → 1.25 拍`，起点/音高不动；回来逐字等于出发前。
- **撤销 / 重做**：改完 `Ctrl+Z` 逐字回到原样、`Ctrl+Y` 又回到改后那一份、再撤又回到原样 —— 三个来回。
- **连续操作**：挪 → `Ctrl+Z` → 再挪，两次挪的落点**逐字相同**。
- **删音符**：删完回落到了邻居（本单这条路上 19 号那段逻辑还活着）；`Ctrl+Z` 之后**悬停原坐标**
  读数逐字等于删之前 —— 文档原样回来了。
- **删整条轨**（轨头「删除」→「删掉这条轨？」两下）：选中集**整块清空**（读数条上五格全没了，
  不是冒出一个别条轨的音）；`Ctrl+Z` 把整条轨放回来，悬停原坐标逐字等于删之前。
- **21 号那套回归**（`.scratch/verify-21.ps1`，24 条）也重跑了一遍，**全过** ——
  31 动过 `PianoRollLane` 的悬停那一路，而 21 的读数栏正靠它。

**写脚本时发现、值得记下来的一条更正**：我原先以为「↑/↓ 挪音高跨过邻居」也会重排数组
（31 号的交接清单里就是这么写的）。**不对**：`Track.WithNotes` 是
`OrderBy(n => n.StartTick)` —— 只按起点，而且是**稳定**排序，所以**挪音高根本不重排，
挪时间才重排**。差一点就照着「音高跨邻居」去量，那样量的是一个**不会发生**的重排，
再配上「逐字回到原样」这种一定过的断言，会得出一条看着很硬、其实什么都没测的结论。

**跑出来才知道的一条行为**（不是 bug，是脚本第一版写错了期望）：
**撤销不动选中集**。删一个音 → 选中回落到邻居 → `Ctrl+Z` 把音放回来，
但**选中留在邻居上**，不是跳回被恢复的那个音。理由是选中集属于界面、不进撤销栈
（撤销恢复的是文档）。脚本里那条断言红了之后改成了量「文档回来没有」（悬停原坐标 = R0），
并把「撤销之后选中仍指着一个存在的音」单列一条。**要改成「撤销顺手选回被恢复的音」
是另一件事，得先把选中集放进撤销栈 —— 不在本单范围。**

**没验的，按风险排：**

1. **两个一模一样的音**（同轨、同音高、同起点、同时值、同力度；旧镜像认不出来的正是这一对）
   —— **界面上没构造出来**。正常语料里那是数据异常，扫一条轨未必碰得到；要造它得先有个
   「复制这个音」的入口，而界面没有。性质相同的断言在单元测试里
   （`重排之后坐标仍指同一个音`），但**界面这一层没量过**。这是本单最该盯、也最够不着的一条。
2. **拖动那一路**（卷帘上真的按下 - 拖 - 松）**没走过**。verify-31 全程是方向键微调 + Delete + 删轨；
   `OnNotesMoved`（增量）和 `OnNoteResized`（绝对值）这两条**请求形状不同**的路，
   最后虽然都汇到同一个 `ApplySong`，但合成一次拖拽要 mouse down / move / up 三段，脚本里没做。
3. **框选 / Ctrl+点加减选之后再挪**：多选时的落点同上，没量过。
4. **焦点轨**（`Ctrl+↑/↓` 换的那条）在编辑之后还在不在原来那条上 —— 它靠 `SyncLanes` 里
   现问「哪个轨头是亮的」，和被删的镜像无关，但没量过（读数条上的「轨」是**音符**在哪条轨，
   不是焦点轨，所以量具够不着它）。
5. **改速度 / 改移调**也走 `ApplySong`，但**它们不动音符**，选中集「原样留着」必然成立 —— 没单独量。
6. **抽掉一段**之后选中集清空（和删轨同一条路，理由不同：剪断的音拿**新身份**，
   被前移的音**保留身份**，于是「原样留着」是半对半错）—— 没单独量。
