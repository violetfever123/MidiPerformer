# 33: 走带条的「■ 停止」改成「↻ 重头播放」

**What to build:** 编辑窗口走带条右边那颗按钮：`■ 停止` → **`↻ 重头播放`**。
按一下 = **播放头回开头 + 视野回第一小节 + 立刻开始放**（不再是「停下来」）。

**几处要说清楚的决定：**

- **图标用 `↻`（U+21BB）。** 2026-09-20 问过用户，三选一（`⏮` / Lucide 矢量 / `↻` 字形），
  用户选 **`↻` 字形**。字形跟着字体走，不引任何图标依赖，和走带条现有的 `▶ ⏸ ■`
  是同一套做法（那三个也是字符）。
- **按一下是「回开头**并立刻播」，不是「回开头并停在那」。**
  这是问过用户的（另两个选项是「回开头停下」和「回开头接着播」）。
  所以它的落点不是 `_playback.Stop()`，而是 `CenterOnBar(0)` + 寻址到第一小节的 tick + `StartPlayback()`。
- **寻址照抄导航条那一支**（`OnNavSeek`）：`TickOfBarClamped(0)` →
  `Song.TempoMap.SecondsAt(tick)`，而不是硬写 `SeekSeconds(0)`。
  两处对「开头」的定义必须是同一个 —— 手写 0 在今天等价，但等哪天第 0 小节不等于 0 秒，
  两处就会不一样，而那时没有人会想到要来搜这一颗按钮。
- **原来那颗按钮丢掉的是「停下 + 视野对齐小节线」。** 「停在这、等下接着听」是**暂停**
  （空格 / 播放键，20 号工单），放完自动停也还在（`OnPlaybackFinished`）。
  真正少掉的是「我听完了、视野回小节」这一下 —— 现在它由重头播放顺带做掉，而且做得更狠（回**第一**小节）。
  这是知道的代价：**没有「不播、只回小节」的路了**。
- **`StopPlayback()` 不删。** 放完自动停那条路还走它（`OnPlaybackFinished`）。
  删掉的只有 `OnStopClick` 和按钮本身 —— 删方法会顺手把「放完自动收尾」也删掉。
- **置灰判据跟着播放键走：`_song is { Tracks.Count: > 0 }`。**
  从前是 `_song is not null`（20 号的决定：■ 始终可用，因为「停下」对空谱面也有意义）。
  重头播放的意义就是**放**，一条轨都没有时按了也没东西可放 —— 播放键灰它就该灰。
- **提示语换成新的**，口径照 26 号：说清按下去会发生什么 ——
  「重头播放：播放头回开头、视野回第一小节，立刻开始放」。
  `■ 停止` 那句「停下来（急停是 F6）」**跟着按钮一起没了**：F6 的提示本来就在**演奏器窗口**
  （`PerformerWindow.axaml:258`「F6 急停」、悬浮层里两处），编辑窗口这句是**第二处**，
  而钩子只在演奏器窗口开着的时候才装着 —— 挪掉它反而更准。
- **演奏器窗口那颗 `■ 急停`（`PerformerWindow.axaml` 的 `StopButton`）一个字节都不动。**
  那是另一件事（全局急停），名字撞了而已。**改的时候按文件名+行号改，不要按名字全仓替换。**
- **26 号工单钉住的那条测试要改写**：`ShortcutHintTests.停止的提示一个字都没动`
  钉的是这句 ToolTip —— 那句话和那颗按钮一起作废。改写成钉**新事实**
  （走带条上没有 `StopButton` 了、新按钮的提示是新的那句），不是删掉它：
  26 号那条测试存在的理由是「有人把按钮加回来会先在这里红」，这个理由还成立。
  同理 `verify-26.ps1` §5 和它的表头。
- **`docs/wireframe.html` 的走带条**（`#btnstop`）跟着改，但只改那一颗按钮的字与说明：
  wireframe 是「画成什么样」的底稿，不写实现。

## 哪些是测出来的、哪些只是写出来了

**测出来的**（真机、真窗口、UIA 读控件；三份 log 都在 `.scratch/`，都没进版本库）：

- 三态**三种起点各试一遍**：正在播（§3）、暂停中（§4）、已放完（§5）。
  三条都走同一个 `RestartPlayback`，但进来的状态不同 —— 只试一种的话，
  「暂停中按 ↻ 卡在『▶ 继续』上」这种错看不出来（§4 专门有一条断言钉它）。
- **「立刻在播」不是靠「位置 = 1」算数**：§3/§4/§5 每一条都在「回到 1」**之后又等 3 秒读一次**，
  读到 **3** —— 一个「回开头然后停住」的实现、或者干脆什么都没做的实现，过不了这三条。
- 灰 / 亮两态都量到了（§1 灰、§2 亮），而不是只量「装了曲子能按」。
- 「■ 停止 没了」量的是**窗口里读不到**（0 个按钮 + 0 处那句话），不是「文件里搜不到字符串」。

**只是写出来了、没测到**（别把它当成验过的）：

- **「视野回第一小节」**。UIA 读不到视口 —— 卷帘滚到哪儿是一个渲染事实，
  树里没有对应属性，26 号量省略号时也栽在同类事情上（那条最后只能截图给人眼看）。
  代码里 `CenterOnBar(0)` 那一句在，但**屏幕上确实滚回去了没有，只有人眼能确认**。
  脚本能作证的只有「播放头回 1」。
- **演奏器窗口的 `■ 急停`**：只到**文件级**（git 干净 + 文本里那三样还在）。
  **没有打开那个窗口看过** —— 打开要装全局钩子、走倒计时，代价和风险都不属于这一票。
- **图标好不好看**：`↻` 是用户选的，脚本只证明按钮上写的就是那五个字符。
- **「播放头回开头」和「视野回开头」是同一帧动的**：脚本分别量不到同时性（后者根本量不到）。

## 给下一个人的坑

1. **「回到第 1 小节」只有 180 毫秒的窗口量得到。** BPM 240（约 2 小节/秒）下，按完 ↻
   读到的是 **2** —— 那不是「没回开头」，是**尺子太快**（settle 拉到 800 毫秒一样读到 2）。
   现在 BPM 用 **120**（约 1 小节/秒）、按完只等 **180 毫秒**。同一把尺子的另一头也一样：
   原速 50 下 3 秒读不出位置变化，那会让「在往前放」那几条变成假绿。
   这是 33 号第一次跑 5 条红里的 3 条，跟 app 一点关系都没有。
2. **`verify-33.ps1` 里一个 `按空格` 都没有**（起播 / 暂停走播放键的 `InvokePattern`）。
   原因：空格是**窗口级**的键，焦点落进输入框就被打成字符。第一次跑第 4 节时按钮还停在
   「⏸ 暂停」、位置从 4 爬到别处 —— 看着像「暂停坏了」，其实是键没到。
   播放键的 Invoke 和空格走的是**同一条 `TogglePlayback`**，所以覆盖没少。
3. **verify-20 里那两处焦点坑，是量出来的、不是想出来的**（抬头和 `松焦点`/`按空格` 的注释里写着）：
   · `Take`（拽前台）里的 `SetFocus(h)` 会把焦点**打回最后一次聚焦的输入框** —— 于是那发空格
   进了框；所以 `按空格` **不再无条件拽前台**（app 一直是前台，掉了才拽）。
   · UIA 的 `FocusedElement` **会过期** —— 读到 `MenuItem 文件` 时真实焦点还在 `RestartButton` 上
   （前一句 ↻ 的 Invoke 留下的），那发空格于是变成「又按一次 ↻」。所以不能「先读一眼再决定挪不挪」，
   得**先无条件 Tab 两下**。
   落点安不安全也是量出来的：`.scratch/probe-20-space.ps1` 里焦点停在菜单条上时那发空格
   照样冒泡到窗口 —— 这正是 app 自己的假定（走带那两颗按钮 `IsTabStop="False"`，
   `MainWindow.axaml` 里那段注释写着为什么）。
4. **换了走带条右边那颗按钮，要顺手改四处，不然红了别怪路**：`ShortcutHintTests`、
   `verify-20.ps1`（§0 的判据、§2 的「↻ 可用」、§4 整节）、`verify-26.ps1`（§5 与 `$预期重播`）、
   `docs/wireframe.html` 的 `#btnstop`。
5. **演奏器窗口那颗按钮叫同一个名字 `StopButton`。** 按**文件名 + 行号**改，别按名字全仓替换 ——
   那一颗是全局急停，语义完全不同（33 号只碰了编辑窗口那一颗，§6 钉着这件事）。
6. **`StopPlayback()` 留着不是忘了删**：放完自动停走它。删了会顺手把「放完自动收尾」也删掉。
   删掉的只有 `OnStopClick` 和按钮本身。
7. **「不播、只回小节」这条路没有了** —— 这是问过用户、知道的代价。
   真想要它，就是把 `RestartPlayback` 拆成「寻址」和「起播」两半、旁边再加一颗；
   **别把 ↻ 改成不播**（那是把用户选的语义又改回去）。
8. **`LanesHost`（卷帘容器，全窗唯一显式 `Focusable="True"` 的元素）在 UIA 树里读不到**
   —— 按 `AutomationId` 找得 **0 个**。想从外面点 / 聚焦卷帘的话，这条会先绊你一下。
