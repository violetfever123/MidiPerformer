# 27: 清理与文档同步

**What to build:** 把不再成立的东西删干净，把三份文档改到和代码一致。

**几处要说清楚的决定：**

- **删 `LaterText` 占位灰字。** 轨头那行现在写着「只看这条 还没做」。
  **独奏这个功能确认不要了**，于是这行**没话可说** —— **整个元素删掉**，不是改成别的字。
  （确认过：这个功能**从来没有实现过**，只有这行占位文字，所以删除是纯删文字。）
- **删演奏器窗口的常驻风险横幅**（`Border.risk` 那两行）：
  `虚拟输入违反游戏规则，可能导致封号，风险自负。` + `本程序只做一件事：往系统里发按键…`
  —— **但要保留启动失败的诊断**（「没开始：要以管理员身份运行 / 输入法现在是中文 / 这条轨弹不了」）。
  那是**唯一**告诉你「为什么没开始」的通道；删了你只会看到一句「没开始。」，然后无从下手。
  - **代价说清楚**：那句「风险自负」是自用工具上唯一的风险提示。删了不影响任何功能，
    但以后给别人用就没这句话了。**这是有意接受的**。
- **文档三份**：
  - **`docs/spec-演奏器.md`**：把**独奏**和**循环**都标成**明确去掉**。
    循环**原本就是按这个方式处理的**（文档里已有「循环播放 —— 明确去掉」），独奏照着办。
    独奏现在写在需求第 22 条。
  - **`docs/wireframe.html`**：**它本来就是旧的** —— 它的读数提示早就和 `Format.ReadoutHint`
    对不上，而且它的读数条只有 **4 格**、代码里是 **5 格**。补上按钮分组（23 号工单）
    和新读数栏的形态（21 号工单）。
  - **`docs/prototype-聚焦轨.html`**：Q12 那条空格决定
    （「空格 = 播放的快捷键；**播放中按空格没反应**（和按钮一致…）」）
    **已被 20 号工单推翻**，照实改，并写上推翻的理由（当时没有暂停可切）。
- **注意**：`TokenParityTests` 会拿 `wireframe.html` 里的**令牌值**做断言。
  改 wireframe 时**只动结构和文案，不要动颜色值** —— 动了颜色值会让 `TokenParityTests` 挂，
  而那不是这条工单想干的事。
