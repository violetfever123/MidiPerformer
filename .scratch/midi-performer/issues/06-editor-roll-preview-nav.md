# 06: 编辑器：卷帘 + 试听 + 导航（只读）

**What to build:** 能看见谱子、能听、能在曲子里快速定位。**这一块还是只读的，改不了任何东西。**

- **卷帘**：所有轨上下堆叠同时显示；固定显示 4 小节，**不支持缩放**；每轨自动适配音域显示范围；超出可演奏范围的音标灰。
- **导航条**：显示整曲的音符密度缩略图；拖动时按小节吸附；**拖动过程中播放头红线隐藏**（否则红线跟着吸附一跳一跳，非常烦），松手后红线出现在新位置；另外提供一个输入小节号直接跳转的入口。
- **悬停**：鼠标移到音符上显示音高、小节、拍、时值；键盘也能定位到具体音符。
- **试听播放**：多轨一起出声（winmm → Microsoft GS Wavetable Synth），复用 02 建好的 `Core/UseCases/Timeline/SongWalker` 做音乐时间 ↔ 物理时间的积分。播放头自动跟随，停在屏幕偏左三分之一处。**无循环**——放完自动停止并释放所有正在响的音。
