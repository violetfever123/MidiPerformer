# 11: 导出 MIDI

**What to build:** 把改完的 `Song` 写回标准 MIDI 文件，这样能在别的软件里用它。

写回走 `Core/UseCases/Project/SongProject`——那是全程序**唯一**许碰 DryWetMidi 的文件，和 MIDI 导入是同一个文件的两半。这一块同时也是 S1 缝的另一半：「导入 → 导出 → 再导入 = 同一个 `Song`」那句断言就落在这里。

移调**在导出时才叠加**，不写回音符——音符本身永远是导入时的原始音高。轨名和音色一起写出去。

导出是单独的按钮，**不覆盖 `.mproj`**。
