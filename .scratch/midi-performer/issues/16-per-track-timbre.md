# 16: 每条轨一个音色（「音色选择功能没做」）

**What to build:** 轨道头上多一个 GM 音色下拉（128 项），选中就换这条轨**试听**用的音色。
鼓轨（9 号声道）不给下拉，那一格换成一句不能点的「音色 标准鼓组 · 通道 10」。

**几处要说清楚的决定：**

- **音色只影响试听**。发给游戏时永远是口琴那套键位（`Format.ProgramNames[22]`），
  音色改的是本机 WinMM 合成器怎么响，不改任何一个音符、不改导出、不改演奏。
- **音色是「声道事件」，不是「音符事件」** —— 这是这一切片真正的坑。一个文件里两条轨
  都在 0 号声道（格式 1 的 MIDI 最常见的形状）时，后一条轨那条 `ProgramChange` 会把
  前一条的音色一起顶掉。所以试听这一侧必须**一条轨一个声道**：`PreviewMixer` 分声道，
  声道和音色跟着**每个音**走（`PreviewNote`），而不是当成一次性的端口状态。
- **9 号声道是鼓组**，打击乐轨发到那儿，而且**不占**旋律声道的名额；旋律轨跳过 9 号，
  15 个用完就绕回来和第 1 条共用（写出来的代价，不是碰巧 —— 另一边是「第 16 条干脆不出声」）。
- **`MappedNote` 一个字节都不能动**：`PortFidelityTests` 钉着 `NoteMapper.cs` 那四个文件
  是原程序的**有序子序列**，所以试听这侧另开了一套自己的词汇
  `PreviewNote(MappedNote Note, int Channel, int Program)`。
- **`SetProgram` 不特判 9 号声道**：模型不该知道表现层怎么排声道。鼓轨那个分支是**纯界面**的
  （`Bind` 里按 `track.Channel == PreviewMixer.PercussionChannel` 二选一亮谁）。
- **撤销白捡**：`UndoableSongEditor` 是装饰器，`SetProgram` 挂上去就自动有一笔撤销。
- **出声验不了，但「哪个音发到哪个声道、带哪个音色」验得了** —— 那部分是纯函数，所以有测试。

**Blocked by:** 无（试听那条链 13 就有了，这一切片只往上加了一层）

**Status:** done

## 哪些是测出来的、哪些只是写出来了

**机器测过的（新 19 条，全套 1505 条全绿，编译 0 警告 0 错误）：**

- `PreviewMixerTests` 8 条：一条轨一个声道并带上自己的音色 / **文件里同一声道的两条轨在
  试听里也分开**（这一条是核心）/ 打击乐轨发到 9 号而且不占名额 / 旋律轨跳过 9 号、超过
  十五条绕回来 / 移调照叠、时间换成秒 / 超出音域的音照发 / 空曲子摊出空表。
- `SongEditorTests` 7 条：只改目标轨、别的轨一个字节不变、没变就返回同一份、非法号抛中文错
  （−1 / 128 / 9999）、0 和 127 合法、轨下标越界也抛中文错。
- `UndoableSongEditorTests` 2 条：换音色可以撤销、音色没变时不记这一笔。

**跑起来量过的**（.scratch/uia-check.ps1 / uia-check3.ps1，走 UI Automation 量控件的真几何）：

- 导入 Carulli 二重奏 → 轨道头上真的有下拉，显示的就是文件里的音色
  （`尼龙弦吉他 · GM 25` ×2、`小提琴 · GM 41` ×2），展开能列出项，选中 `口琴 · GM 23`
  之后那一格的字跟着变，按撤销又变回 `尼龙弦吉他 · GM 25`。
- 鼓轨那一支用 `cargo.mid` 量了：**11 条轨 = 10 个下拉 + 恰好一处
  「音色 标准鼓组 · 通道 10」** —— 一个不多一个不少。

**没验的，按风险排：**

- **`WinmmPreview` 里那段出声的路径**：`ProgramChange` 只在一个声道第一次出声前发一次
  的缓存、逐声道的按住的音计数、`ResetDevice` 扫 16 个声道。这些**要出声才验得了**，
  而试听会真的响，所以这里只是写出来了。风险最高的一条 —— 「音色是声道事件」这个
  认识如果哪里错了，就错在这一段。
- **>15 条旋律轨绕回来**：有单测钉住「第 16 条和第 1 条共用声道」，但那种曲子真播起来
  是什么样没听过。
- **下拉本身的观感**：128 项的 `MaxDropDownHeight=320` 够不够用、翻起来顺不顺手、
  轨道头一行加了这一格之后挤不挤（11 条轨那个文件量下来没出界，但没好看不好看这一说）。
- **换音色时正在响的那一遍**会不会立刻换音色，没验。
