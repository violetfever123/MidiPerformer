# 09: 卷帘上的指针交互

**What to build:** 让卷帘真的能改。

- **坐标换算**：`PianoRollGeometry` 是纯函数，负责像素 ⇄ (音高, tick) 和命中判定。**Controller 方向（像素→tick）和 Presenter 方向（tick→像素）是互逆的**，放一起测一次往返恒等就覆盖两边。卷帘编辑器最容易出的 bug 全在这里。
- **`PianoRollController`**：全项目**唯一**的 Controller，因为只有它做真换算。其余「点按钮 → 调命令」是纯管道，位置由 Avalonia 的 ViewModel 占着，不另造类。
- **交互**：拖动音符左右边缘改时值；上下拖动改音高；框选一组一起移；空白处横拖删掉区间内所有音；方向键微调（左右移时间、上下移音高、加 Shift 改时值）；改动吸附到网格；删轨带二次确认；轨重命名。

全部改动都走 08 立好的脊柱，撤销自动生效。
