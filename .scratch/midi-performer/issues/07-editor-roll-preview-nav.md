# 07: 编辑器：卷帘 + 试听 + 导航（只读）

**What to build:** 能看见谱子、能听、能在曲子里快速定位。**这一块还是只读的，改不了任何东西。**

- **卷帘**：所有轨上下堆叠同时显示；固定显示 4 小节，**不支持缩放**；每轨自动适配音域显示范围；超出可演奏范围的音标灰。
- **导航条**：显示整曲的音符密度缩略图；拖动时按小节吸附；**拖动过程中播放头红线隐藏**（否则红线跟着吸附一跳一跳，非常烦），松手后红线出现在新位置；另外提供一个输入小节号直接跳转的入口。
- **悬停**：鼠标移到音符上显示音高、小节、拍、时值；键盘也能定位到具体音符。
- **试听播放**：多轨一起出声（winmm → Microsoft GS Wavetable Synth），复用 02 建好的 `Core/UseCases/Timeline/SongWalker` 做音乐时间 ↔ 物理时间的积分。播放头自动跟随，停在屏幕偏左三分之一处。**无循环**——放完自动停止并释放所有正在响的音。
- **窗口一的外壳**：顶部工具栏（导入 / 保存 / 导出 / 启动演奏 + 文件名框）、底部走带条（播放 / 停止 / BPM / 步进器 / 无循环标记）、状态栏。按 wireframe 的位置排布。**本切片只负责这些构件的位置和外观**，按钮按当时已有的命令接线，其余先置灰——功能分别归 10（导入/保存）、11（导出）、06（启动演奏）、08（BPM 与移调）。没有这一步，最后会得到一个有卷帘、没工具栏的窗口。

## 未验证

本切片的代码全部编译通过、930 个测试全绿，但**一次真窗口都没起过**（没有可交互的桌面会话）。
下面这些请**人**在 Windows 上跑一遍：

1. **外观与 wireframe 的逐格比对**（工具栏 / 导航条 / 读数条 / 走带条的位置与间距，卷帘的小节线、拍线、音符块的观感）—— 由主协调者或美术过一眼，对着 `docs/wireframe.html` 的窗口一。
2. **标灰的音看着是不是「灰」**（`PianoRollLane.DrawNote` 用的是 `InkFaint` 填充 + `Line` 顶边，理由是这两个令牌在深浅两套主题下都明确比 `Note` 弱、又不至于看不见）。随手导入一首跨音域大的曲子就能看出来。
3. **悬停读数**：鼠标移到音符上四个格子（悬停 / 小节 / 拍位 / 时值）出数，移开回到「—」；键盘 ← → 在窗口里真的能走（焦点在跳跃输入框里时不能被抢走）。
4. **试听播放**：点「▶ 从当前位置播放」真的出声（多轨一起响，GS 软波表的音色），红线按三分之一处跟着走、到曲子末尾自动停、**松开所有音**（不该有音卡住）；「■ 停止」随时能停，停下后视图对齐到小节线。
5. **拖导航条**：拖动时整屏没有红线、松手后红线出现在新位置；跳跃输入框里输小节号回车上跳。
6. **导入**：`导入 MIDI…` 选一个 `.mid` 能读进来（失败时报中文错，不崩）；「歌曲名」框里显示文件名。
