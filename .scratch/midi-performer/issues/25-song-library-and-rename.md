# 25: 曲库与改名（内联改名、悬浮看全名、空状态文案）

**What to build:** 改曲名和改轨名都不再需要单独的按钮，直接点名字就能改；
鼠标停在曲库某一行上能看到完整曲名。

**几处要说清楚的决定：**

- 三处改名的现状各不相同：
  1. **曲库行**：一个 `改名` 按钮 + 弹窗
  2. **轨头**：一个 `改名` 按钮 + 一个点了才出现的隐藏 `NameBox`
  3. **工具栏 `SongNameBox`**：**本来就是**可直接编辑的方框，和速度框同款。**③ 不动**——
     它已经是想要的样子，是这次改造的样板。
- **轨头**：`NameBox` **常驻显示**（不再藏在按钮后面），**删掉 `RenameButton`**。
  回车确定 / Esc 取消的现成逻辑保留。
- **曲库行**：**点名字那一小块就进编辑**（名字区域本身变成输入框）。
  **这里有个冲突要说清楚**：列表行现在是**单击选中、双击打开歌曲**，所以「双击进编辑」
  会和「双击打开」直接打架。**所以用单击名字**，而不是双击。
- 行的其余部分照旧负责**选中 / 双击打开**；`F2` 改名**保留**（键盘路径不能因为改了鼠标路径就没了）。
- 改名后行的列从 `名字 / 元信息 / 改名 / ×` 变成 `名字 / 元信息 / ×`，名字那一栏自然能宽一点。
- **悬浮显示完整曲名**：给名字那个 `TextBlock` 加 ToolTip —— 它现在有 `TextTrimming`（长名字会出省略号）
  但**没有 ToolTip**，所以被截断的名字目前**根本看不到全的**。
- ToolTip 里**只放完整曲名**，**不带**「改过 / 没动过」那类元信息。理由：悬停是为了读全名字，
  掺进元信息反而让人分不清哪个是名字。
- **删掉曲库脚注**「导入的曲子存进这个文件夹，改名就是改文件名」**整条删除**。
  （实际文案用的是「文件夹」不是「文件」。）
  后半句在**改名内联化之后就依然是错的** —— 现在改名不再只等于改文件名了（曲库改名写的是工程里的
  曲名），留着就是错的，更要删。
- **两处空状态文案改短**，而且**不能再靠位置描述指向按钮** ——「导入 MIDI…」要进「文件」菜单
  （23 号工单），所以现在这两句话里的「点左上角「导入 MIDI…」」「点上面的「导入 MIDI…」」
  **全都指错地方**。改成：
  - 主窗口卷帘区 → `还没有曲子 —— 把 .mid 拖进这个窗口，或从「文件」菜单导入。`
  - 曲库面板 → `还没有曲子`
  两句话**不提位置**，只说做什么（拖进来 / 去「文件」菜单），菜单再怎么挪都不会过期。

**Blocked by:** 无（可以立刻开工）
