# 21: 读数栏合并 + 位置读数搬迁 + 删时长 + 删「没有循环」

**What to build:** 底部读数栏里「悬停」和「选中」两套读数合成一套；
运输条上的位置读数搬到「跳到」左边、原来的视图范围文字让位；删掉「时长」；删掉「没有循环」四个字。

**几处要说清楚的决定：**

- 读数栏现在是 **6 栏**：`悬停`(音高) / `小节` / `拍位` / `时值` / `选中`(=`轨 01 · C4（1）· 1.00 拍`) /
  右边快捷键提示。
- **合并成一套**：`轨 / 音高 / 小节 / 拍位 / 时值`。值来源是**悬浮的音优先，没悬浮就用主选中的音**
  （主选中 = 选中集里最后加进去的那个）。
- **轨号要留下。** 合并之后它是「这个音在哪条轨」的唯一线索。
- 两者都没有时，**标签和值一起隐藏**，只留右边的快捷键提示；但**保留这一条的高度**
  （那个 `MinHeight` 不动），否则鼠标一移开整窗会跳一下。
- **合并带来的行为变化**：悬浮时显示悬浮的音，鼠标一移开**回落到当前选中的音**（不是变空）。
  这是「合并」的直接兑现，不是副作用。
- **位置读数搬到导航条上视图范围文字占的那个格**（「跳到」左边）；**删掉运输条上的「位置」栏**。
- 视图范围文字（`第 1–4 小节 / 共 96`）被**取代** —— **视图范围的文字表达彻底消失**，
  只剩缩略图上的视口框。`Format.BarRange` 一并删掉（它只剩这一个调用者 + 一条测试）。
  理由：缩略图上的框已经在视觉上表达了「我在看哪一段」，文字是重复。
- 位置读数**显示播放头所在小节**（和现在一致，不改成视口起始）——
  它旁边就是「跳到某小节」的输入框，显示播放头才形成「我在哪 / 我要去哪」的对照。
- **删掉运输条上的「时长」栏**（标签和值都删）。
- 「没有循环 · 放完自动停止并松开所有按键」**只删「没有循环」四个字**，
  **保留后半句安全说明** —— 它说的是演奏结束会把手按住的键全松开、不会卡键，
  这是真有用的信息；而「没有循环」是给外人解释设计取舍的。
- **这条不改 `HintText`。** 那句话提到的东西要等 18/19/20/23/25 全部落地才写得对，归 26 号工单。
