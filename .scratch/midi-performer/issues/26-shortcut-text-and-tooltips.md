# 26: 文案收口（快捷键提示与各处 ToolTip）

**What to build:** 屏幕上所有写死快捷键的地方，和最终键位对上。

**几处要说清楚的决定：**

- **`HintText` 现在是错的。** 它提到的东西被 18/19/20/23 改了：`空格 播放` 变成了播放/暂停、
  `Ctrl+←→ 前后跳` 变成了同轨前后跳、`Delete` 根本没提。改写为：

  > 空格 播放/暂停 · ← → 移时间（一格 = 十六分）· ↑ ↓ 移音高 · Shift + ← → 改时值 ·
  > Ctrl + ← → 同轨前后跳 · Ctrl + ↑ ↓ 换轨 · Delete 删除 · Ctrl+Z 撤销 / Ctrl+Y 重做

- 这行**右对齐挤在一个 `*` 列里**，而窗口最小宽度只有 720px，左边还压着**合并后**的读数栏
  （21 号工单）—— 写完大概率会溢出。所以同时做两件事：
  1. 给它加 `TextTrimming="CharacterEllipsis"` 兜底
  2. 把**完整版塞进 ToolTip**

  结果：屏幕够宽就全显示，窄了自动省略号，鼠标一停看全的。
- **三处 ToolTip 修正**：
  - **播放/暂停按钮**：现在是「从播放头当前位置开始试听（空格键同效）」，
    改成与 20 号工单新行为一致的说法（不再是「开始」而是「播放 / 暂停」）
  - **撤销 / 重做**：按钮进了「操作」菜单（23 号工单），快捷键已经写在菜单项右侧，
    **原来的 ToolTip 删掉** —— 不要两处都说同一件事
  - **轨头 `改名` 按钮的 ToolTip**：随按钮一起删（25 号工单）
- **`■ 停止` 的 ToolTip 保留不动**（「停下来（急停是 F6）」依然准确，F6 没被改过）。
- **这条必须等 18/19/20/23/25 全部落地。** 它们是这句话的**四个真相源**，
  任何一个没做完，此刻写出来的提示就是错的 —— 而一句错的快捷键提示比没有提示更坏，
  它会让人以为功能坏了。

## 给下一个人的坑

- **窗口摆到任务栏底下，ToolTip 就永远弹不出来。** 这台机器是 3072x1920 的屏、**工作区只有 1824 高**
  （任务栏从 y=1824 起）。harness 默认那处 2360x1520 @ 405,450 底边落在 **1970** ——
  读数栏那一行（y≈1826）正好被任务栏压住：悬停它时那个点上压的是任务栏，
  UIA `FromPoint` 读到的是任务栏那个**无名 `Pane`**，看着就像「这个 app 不弹 ToolTip」。
  先怀疑过 Avalonia 的 ToolTip 整体不弹，量了三支探针（probe26b/c/d）才钉到任务栏头上。
  **凡是要悬停读数栏/按钮条那两行的验收，窗口底边必须留在工作区里**：这一票摆 2360x1300 @ 405,300。
- **Avalonia 的 ToolTip 是另一个顶层窗，而且它的 UIA 子树是空的。** `FromHandle(纸的句柄)` 拿到的
  是个 `ControlType.Window`、框也落在纸的位置上，但 `FindAll(Descendants, …)` **一个都搜不到**
  （连 `ControlType=Text` 都是 0 个；`TreeWalker` 从它往下会一路走回主窗的内容）。**只能按点读**
  （`FromPoint`）—— 曲库行那个 ToolTip 也是这么读到的（`Text「cargo」`），同一把尺子。
  搜不到时别急着怀疑「没弹」，先看**顶层窗清单**多没多出一个。
- **「读数栏那一行没挪」不能跟窗口底边比。** 拉窄之后底下那条按钮条自己会长高
  （右边那句「放完自动停止并松开所有按键」换行），整摞往上顶，距窗口底边跟着变
  （第一版就是这么假红的：1812 vs 1825）。跟**上一行**（小节导航那排，拿 `JumpBox` 当锚）比才稳：40 → 40。
- **「ToolTip 里出现 Ctrl+Z 就算重复」是错的尺子。** 提示行自己那句里本来就有（键位表本体），
  轨头那几颗按钮的 ToolTip 正文里也提一句（「只动这条轨，别的轨原地不动 —— Ctrl+Z 可以撤销」）——
  第一版数出 5 个假红。要抓的是「ToolTip 的内容**就是**那个快捷键」（`^\s*Ctrl\s*\+?\s*[ZY]\s*$`）。
- **「全窗没有『改这条轨的名字』这句话」也是错的尺子** —— 25 号把改名从按钮换成轨头名字框，
  ToolTip 跟着挪过去了（4 条轨 → 4 个 `Edit`）。该断言的是它**挂在哪儿**：0 个按钮挂它、
  挂着的全是 `Edit`、个数 == 轨头数（`数轨` 用的是「折叠」按钮数那把尺子）。
- 这台机器上 `SetWindowPos` 要 **2360x1300 实得 2334x1229**（宽 −26、高 −71，固定偏差）。
  写死尺寸的断言会踩，拿 `摆窗` 的**返回值**当准。
